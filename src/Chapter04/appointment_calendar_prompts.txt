* contact_info (varchar 255)
* start_date_and_time (datetime)
* end_date_and_time (datetime)
2. Create a PHP entity class "Cookbook\Appointment\Appointment" that represents a row in the "appointment" table described above.
* Use PHP 8 constructor argument promotion so that property values can be defined upon object instantiation.
* Make all properties public with the appropriate data type.
* Do not create "getter" or "setter" methods.
* The start and end date and time properties should have a data type of string.
* The default value for all properties should be an empty value that matches the data type (i.e. use '' for string, 0, for integers, etc.).
* The "id" column needs to be auto-increment.
